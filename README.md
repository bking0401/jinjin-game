# 合成大金金

单文件 HTML5 合成小游戏，同《合成大奶蛙》一个玩法，十级人像球。

- 在线玩：https://bking0401.github.io/jinjin-game/
- 十级：小迷糊 → 大笑金 → 校服金 → 叉子金 → 攥拳金 → 墨镜金 → 张嘴金 → 泳池金 → 侧颜金 → 至尊金
- 合成音效从第 1 级起就有，每升一级音高与响度各 ×1.2（封顶 2.5 倍音高 / 1.6 倍响度）
- 最后 4 级用预渲染的拉长版音频，一级比一级长约 1 秒
- 首页最下方：感谢天赐为本游戏提供创作资源

整包一个 HTML 文件，图片、物理引擎、音频全部内嵌，断网也能玩。
